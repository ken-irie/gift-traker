# Gift Tracker 🎁

もらったプレゼントを記録・管理するWebサイト

## 機能

- **プレゼント登録**: 名前、受け取った日付、送り主、カテゴリを記録
- **一覧表示**: 登録したプレゼントをテーブルで表示
- **検索機能**: プレゼント名または送り主で検索
- **カテゴリ分類**: カテゴリでフィルタリング
- **編集・削除**: 登録内容の編集や削除が可能
- **データ保存**: ブラウザのlocalStorageに自動保存

```

│   ├── package.json
│   ├── public/
│   │   └── index.html

│       └── styles/
```

## セットアップ

### 必要なもの
- Node.js (v14以上)
- npm または yarn

### インストール

```bash
# ルートディレクトリから
npm install

# クライアントの依存関係をインストール
cd client
npm install
cd ..
```

## 実行

### 開発モード（フロントエンドのみ）
```bash
cd client
npm start
```
ブラウザで `http://localhost:3000` を開くと利用可能

### フル実行（バックエンド + フロントエンド）
```bash
npm run dev
```

## 使い方

1. **プレゼントを追加**
   - フォームに必要情報を入力
   - 「追加」ボタンをクリック

2. **プレゼントを検索**
   - 検索ボックスでプレゼント名または送り主で検索

3. **カテゴリでフィルター**
   - ドロップダウンからカテゴリを選択

4. **編集・削除**
   - 一覧の「編集」ボタンで内容を更新
   - 「削除」ボタンで削除

## データ保存

すべてのデータはブラウザのlocalStorageに保存されます。
- ページを閉じても保存されます
- ブラウザのキャッシュをクリアするとデータが削除されます

## 技術スタック

- **フロントエンド**: React 18
- **バックエンド**: Node.js + Express
- **スタイリング**: CSS3
- **データ保存**: Browser localStorage
